📁 ファイルダウンロード

GitHubにアップロードするファイルをダウンロードしてください

GitHubへのアップ手順
1. 上のボタンで各ファイルをダウンロード
2. GitHub の kabu-judge リポジトリを開く
3. index.html と worker.js を必ず更新
  （該当ファイルを開く → 鉛筆アイコン → Upload new version）
4. Commit changes → 1〜2分待つ
5. kabu-judge を開いて動作確認

worker.js を更新後、GitHub Actions が自動で
Cloudflare Worker にデプロイします（約30秒）。
