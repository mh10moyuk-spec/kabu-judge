# 株式テクニカル判定ツール（PWA）

## プロジェクト概要
ボリンジャーバンドとRCI（順位相関係数）の2指標を組み合わせて、
日本株の「買い / 売り / 様子見」を判定する静的PWAツールです。
iPhoneのSafariでURLを開くだけで動作します（ログイン不要）。

## 対応環境
- iPhone Safari（PWA対応、ホーム画面追加可能）
- Android Chrome
- PCブラウザ全般

## 主な機能

### 実装済み
- **ログイン永続化**：一度パスワードを入力すれば次回以降は不要（localStorage使用）
- **Yahoo Finance 自動取得**：銘柄コードを入力するだけで過去20日の終値を自動取得（allorigins.winプロキシ経由でCORS回避）
- **プリセット5銘柄**：日本駐車場開発(2353)、テリロジーHD(5133)、トモニHD(8600)、アステナHD(8095)、ベルーナ(9997)
- **手動フォールバック**：自動取得失敗時は手動で終値を入力して分析可能
- **ボリンジャーバンド計算**：σ位置・バンド幅（スクイーズ検出）・移動平均
- **RCI計算**：短期(9日)・長期(16日)・GC/DCクロス検出
- **総合スコア（0-100）**：指標を複合して買い/売り/様子見を判定
- **価格チャート**：BB線（±1σ, ±2σ）とローソク終値
- **RCIチャート**：短期線・長期線・±80過熱ライン
- **シグナル詳細一覧**：各指標のシグナルを日本語で表示
- **指標読み方ガイド**：初心者向けBB・RCIの使い方説明
- **PWA対応**：manifest.json + Service Worker でオフラインキャッシュ

## ファイル構成
```
index.html      メインアプリ（HTML+CSS+JS all-in-one）
manifest.json   PWAマニフェスト
sw.js           Service Worker（オフラインキャッシュ）
README.md       本ドキュメント
```

## アクセス方法
Publishタブでデプロイ後、表示されるURLをiPhoneのSafariで開いてください。

### ホーム画面に追加（PWAインストール）
1. SafariでURLを開く
2. 下部の「共有」ボタン → 「ホーム画面に追加」
3. アイコンから起動可能

## 総合スコアの判定基準
| スコア | 判定 |
|--------|------|
| 70以上 | 🟢 買い候補 |
| 55-69  | 🔵 やや買い優位 |
| 45-54  | 🟡 様子見 |
| 30-44  | 🟠 やや売り優位 |
| 30未満 | 🔴 売り候補 / 回避 |
