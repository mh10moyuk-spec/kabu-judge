    📊 ボリンジャーバンド

    移動平均（中心線）を軸に、統計的な価格レンジを示します。

    • -2σ以下 売られすぎ → 反発候補
    • +2σ以上 買われすぎ → 過熱・反落リスク
    • スクイーズ バンド収縮 → 大きな動きの前兆
    • バンドウォーク σに沿い推移 → 強トレンド継続

    📈 RCI（順位相関係数）

    時間と価格の「順位の一致度」を-100〜+100で表します。

    • -80以下→反転 売られすぎ → 買い候補
    • +80以上→反転 買われすぎ → 売り・利確候補
    • GC（ゴールデンクロス） 短期が長期を上抜け → 買いサイン
    • DC（デッドクロス） 短期が長期を下抜け → 売りサイン

    🔗 2つの組み合わせ方

    ボリンジャーバンドで「相場の状況」を把握し、RCIで「エントリーのタイミング」を確認するのが基本です。 例：BB下バンド到達 × RCI短期が-80以下から反転 = 強い買いシグナル
